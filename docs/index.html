Actas de campo

Reporte fotográfico de despacho y recepción de equipos: grupos electrógenos, torres de iluminación, plataformas de elevación y maquinaria de construcción y minería.

Abrir la aplicación Instálela desde aquí en la pantalla de inicio

Ábrala desde esta dirección, no desde un archivo descargado. Un archivo local no puede pedir la cámara del teléfono: el navegador se la deniega siempre. Servida desde aquí, sí.

  • Android: menú ⋮ → Instalar aplicación
  • iPhone: Compartir → Añadir a inicio
  • Una vez instalada abre sin señal. Las fotos no salen del teléfono.
El código y la herramienta de escritorio que genera el Excel y el PDF están en github.com/nilthonnn/nefer.
