# Tipos de generadores
| Criterio | Tipos |
|---|---|
| Principio | **Síncrono** (alternador; grupos electrógenos) · asíncrono o de inducción (necesita red o condensadores) |
| Excitación | Con escobillas (anillos rozantes) · **sin escobillas** ([[Excitación sin escobillas]]) |
| Fuente del AVR | Shunt (autoexcitado) · PMG · AREP → [[Tipos de AVR]] |
| Fases | Monofásico · trifásico |
| Polos | n = 120·f/p → 60 Hz: 2 polos 3 600 rpm; **4 polos 1 800 rpm** |
| Régimen (ISO 8528-1) | Prime · standby · continuo |

Ver también [[Tipos de rotor]] y [[Tipos de devanados]].
