# Árbol de decisiones RCM
1. ¿La falla es evidente? No → [[Falla oculta]]. Sí → consecuencia de seguridad, ambiente u operación.
2. Orden de tareas: [[Tarea a condición]] → reacondicionamiento cíclico → sustitución cíclica → a falta de (búsqueda de fallas, rediseño, ningún mantenimiento).
