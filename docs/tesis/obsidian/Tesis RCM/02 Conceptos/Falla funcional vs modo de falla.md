# Falla funcional vs modo de falla

- **Falla funcional** = el **qué**: el equipo no cumple su función con el estándar (el filtro deja pasar partículas finas).
- **Modo de falla** = el **por qué**: la causa física (filtro de especificación incorrecta o vencido).
- **Efecto** = qué pasa (desgaste de inyectores).
