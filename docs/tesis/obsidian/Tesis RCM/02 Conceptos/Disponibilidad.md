# Disponibilidad

**D = MTBF / (MTBF + MTTR)** (ecuación 4). Ej.: 145,3/(145,3+11,5) = 92,67 %.
Para 97 % con MTBF 145,3 → MTTR ≤ 4,49 h; con MTTR 11,5 → MTBF ≥ 372 h.

Nota: es disponibilidad inherente; la tesis la llama «operativa (Ao)». Ver [[Banco de preguntas/9. Disponibilidad, MTBF y MTTR]].
