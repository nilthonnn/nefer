# Glosario ComAp
| Término | Significado |
|---|---|
| **SPtM** | *Single Parallel to Mains*: un grupo en paralelo con la red [D, [[InteliCompact_NT_Datasheet_2013-06_CPLSICNT.pdf#page=2\|pág. 2]]] |
| **MINT** | *Multiple Island*: varios grupos en paralelo con reparto de carga [D, [[InteliCompact_NT_Datasheet_2013-06_CPLSICNT.pdf#page=2\|pág. 2]]] |
| **AMF** | *Auto Mains Failure*: arranque y transferencia automáticos ante falla de red |
| **MRS** | *Manual / Remote Start*: arranque manual o remoto (InteliLite NT) [I] |
| **GCB / MCB** | Interruptor del generador / de la red |
| **Isócrono** | Mantiene frecuencia constante y reparte carga por comunicación |
| **Droop** | Reparto de carga por caída de velocidad o voltaje con la carga [I] |
| **Vector shift** | Salto brusco del ángulo de voltaje: detecta pérdida de red en paralelo (ANSI 78) |
| **EFI / ECU** | Motor de inyección electrónica / su unidad de control |
| **J1939** | Protocolo CAN de motores; códigos SPN/FMI [I] |
| **AirGate** | Conexión remota de ComAp por internet [D, [[InteliCompact_NT_Datasheet_2013-06_CPLSICNT.pdf#page=1\|pág. 1]]] |
| **Power management** | Encender/apagar grupos según la carga y rotarlos por horas [D, [[InteliCompact_NT_Datasheet_2013-06_CPLSICNT.pdf#page=1\|pág. 1]]] |
| **WRN / BOC / STP / SD** | Aviso / abre GCB y enfría / descarga suave y para / parada inmediata [D, [[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=106\|IC p. 106]]–[[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=107\|IC p. 107]]] |
| **FLS** | Falla de sensor (valor `####`) [D, [[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=107\|IC p. 107]]] |
| **SRO / VRO** | Salida al gobernador / salida al AVR [D, [[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=110\|IC p. 110]]] |
| **SPN / FMI / OC** | Parámetro con falla / modo de falla / contador de ocurrencias (J1939) [D, [[IL-NT-MRS-1.5-Reference Guide.pdf#page=68\|MRS p. 68]]] |
| **Dwell Time** | Tiempo que Δφ y ΔV deben mantenerse en ventana antes de cerrar [D, [[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=189\|IC p. 189]]] |
| **ProtectHoldOff** | Retardo para evaluar protecciones «solo con motor en marcha» [D, [[InteliCompact-NT-1.4-Reference Guide-r4.pdf#page=93\|IC p. 93]]] |
| **IDMT** | Sobrecorriente de tiempo inverso [D, [[IL-NT-AMF-1.5-Reference Guide.pdf#page=65\|AMF p. 65]]] |
